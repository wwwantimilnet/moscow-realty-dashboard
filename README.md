Контекст проекта: Дашборд рынка недвижимости Москвы
Мы разрабатываем серию интерактивных HTML-дашбордов рынка недвижимости Москвы. Текущая версия файла — dashboard_v6.html (прикладываю).
Стек: HTML/JS/Chart.js 4.4.1, SVG-карта из GeoJSON, светлая кремовая тема (#faf8f4), золотой акцент (#b8924a), шрифты Playfair Display + IBM Plex.
Архитектура данных:

Вторичный рынок: Google Apps Script → JSON (два URL: по Москве и по округам/муниципалитетам)
Аренда: данные встроены в HTML как RENT_RAW, при появлении Google Apps Script — одна строка const URL_RENT = 'https://...'
GeoJSON карты: moscow_ao.geojson (округа) и moscow_districts.geojson (муниципалитеты) с GitHub wwwantimilnet/moscow-realty-dashboard

Что уже реализовано:

Три вкладки: ВСЯ МОСКВА / ПО ОКРУГУ / АРЕНДА
Светлая тема, тултипы на карте (название + цена), тултипы на линейных графиках (все серии при наведении, отсортированы по убыванию)
Блок «Комментарий аналитика» — объект ANALYST_COMMENTS в JS, ключ 'YYYY-MM', редактируется прямо в HTML
Карта аренды с переключателем комнатности (Все / Студии / 1-комн. / 2-комн. / 3-комн. / 3к+)
Изменение % к предыдущему месяцу в аренде считается на лету
